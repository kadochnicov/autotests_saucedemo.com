# 🧪 Автоматизация тестирования: SauceDemo (Playwright + TypeScript)

Репозиторий содержит проект с автоматизированными тестами для учебного веб-ресурса [Sauce Labs Swag Labs](https://www.saucedemo.com). Проект создан в рамках обучения автоматизации тестирования и демонстрирует применение современных подходов и лучших практик разработки автотестов.

---

## 🛠️ Стек технологий
* **Язык программирования:** TypeScript (TS) / JavaScript (JS)
* **Фреймворк:** Playwright
* **CI/CD:** GitHub Actions
* **Управление окружением:** Dotenv

---

## 🚀 Прогресс и изученные технологии

В ходе работы над проектом были успешно освоены и применены следующие концепции:

### 📐 Архитектура и паттерны
* **Page Object Model (POM):** Разделение логики страниц и самого текста тестов для улучшения поддерживаемости и читаемости кода.
* **Кастомные фикстуры (Fixtures):** Создание собственных и расширение базовых фикстур Playwright для оптимизации подготовки окружения перед тестами.

### 🧹 Написание тестов и тест-дизайн
* **Продвинутый поиск локаторов:** Улучшен навык составления надежных и стабильных локаторов (CSS, XPath, Playwright Locators).
* **Параметризация тестов:** Запуск одних и тех же проверок с разными наборами входных данных (Data-Driven Testing).
* **Параметризация проекта:** Настройка конфигурации для запуска тестов в различных браузерах и конфигурациях.

### 🔒 Безопасность и оптимизация
* **Глобальный Setup и Авторизация:** Реализация авторизации на уровне фикстур и setup-проектов для исключения повторных шагов логина в каждом тесте.
* **Работа с `.env`:** Безопасное хранение чувствительных данных (пароли, токены, URL стендов) в переменных окружения.

### 🔄 CI/CD
* **GitHub Actions:** Настройка автоматического запуска пайплайна с тестами при пушах и пулл-реквестах в репозиторий.

## 💻 Как запустить проект локально

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com
   cd ИМЯ_РЕПОЗИТОРИЯ
   ```

2. **Установите зависимости:**
   ```bash
   npm install
   ```

3. **Создайте файл конфигурации окружения:**
   Создайте файл `.env` в корне проекта по примеру:
   ```ini
   PRODUCT_URL=https://www.saucedemo.com
   # Добавьте другие переменные, если необходимо
   ```

4. **Запустите тесты:**
   * Запуск всех тестов в консоли:
     ```bash
     npx playwright test
     ```
   * Запуск в интерактивном UI-режиме:
     ```bash
     npx playwright test --ui
